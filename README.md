# Tom

I build **.NET** and **TypeScript** tools that remove boilerplate and improve developer workflows.

> Conventions over configuration. Workflow over noise.

- Based in Hamburg
- Thinking and experimenting with what AI-native developer workflows should look and feel like
- Building practical libraries, workflow tools, and occasionally just fun things I want to have
- Open to collaboration on developer tooling and workflow automation

## Featured Work

- **[SettingsBinder](https://github.com/TomRR/SettingsBinder.Nuget)** - Lightweight Roslyn source generator that binds `[Settings]`-annotated classes to the .NET Options pattern with minimal boilerplate. ([NuGet](https://www.nuget.org/packages/TomRR.SettingsBinder/))
- **[ResultType](https://github.com/TomRR/ResultType.Nuget)** - Robust, type-safe Rust-like `Result` type for C#/.NET to make error handling explicit and reliable. ([NuGet](https://www.nuget.org/packages/TomRR.ResultType/))
- **[script-flow](https://github.com/TomRR/script-flow)** - Tooling project focused on streamlining repetitive development workflows.
